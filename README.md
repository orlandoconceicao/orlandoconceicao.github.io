# Portfólio — Orlando Conceição

Portfólio pessoal estático para apresentar a trajetória, as competências e os projetos de Orlando Conceição, desenvolvido com HTML e CSS e publicado pelo GitHub Pages.

## Acesso

[Acessar o portfólio](https://orlandoconceicao.github.io/)

## Conteúdo

- apresentação profissional com foco em desenvolvimento backend;
- tecnologias e competências organizadas por área;
- seleção de projetos com links para os respectivos repositórios;
- links de contato para GitHub, LinkedIn e e-mail;
- layout responsivo para navegação em diferentes tamanhos de tela.

## Tecnologias

- HTML5
- CSS3
- Google Fonts
- Devicon
- Ionicons

## Execução

O projeto não exige instalação de dependências. Clone o repositório e abra o arquivo `index.html` no navegador:

```bash
git clone https://github.com/orlandoconceicao/orlandoconceicao.github.io.git
cd orlandoconceicao.github.io
```
