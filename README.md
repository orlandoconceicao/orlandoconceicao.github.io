# Orlando Conceição — Portfólio pessoal

Portfólio pessoal estático para apresentar Orlando Conceição como desenvolvedor backend, com foco em Python, Django, Django REST Framework, PostgreSQL e APIs REST.

## Estrutura

- `index.html` — página principal
- `css/styles.css` — estilos visuais e responsivos
- `js/script.js` — animações e navegação suave
- `favicon.svg` — favicon do site

## Como visualizar localmente

Abra o arquivo `index.html` diretamente no navegador ou execute um servidor estático local, por exemplo:

```bash
python -m http.server 8000
```

Depois acesse:

```text
http://localhost:8000/
```

## Observações

- O conteúdo foi desenvolvido do zero, sem reutilização de identidade visual ou textos de projetos anteriores.
- O foco principal do portfólio é backend, mantendo React e TypeScript como tecnologias complementares.
- Os links externos foram configurados com as URLs fornecidas.
